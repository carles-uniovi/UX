Help

How do I find something?

Use the menu, site map or search in the header. In Hobbies and Interests, the links below the title jump to each category.

How does search work?

Type one or more words, such as “judo”, “Robe” or “Web Engineering”. Search ignores case and accents. With multiple words, it looks for content containing all of them. Results show the section and a link to the content. If nothing matches, try fewer words, choose an example or use the site map. Clear removes the query so you can start again.

Can I use only the keyboard?

Press Tab to move forward and Shift + Tab to move back. The first link skips to the content. Enter activates links and buttons; Space also activates buttons and opens questions. On mobile, the Menu button opens navigation and Escape closes it. Media players have their own keyboard controls.

How do I read without images or distractions?

The reading version brings together the personal content from all five sections on one page, with a contents list and text links. You can also print it. Navigation and content remain available if you disable CSS, images or JavaScript.

How do I change the language or theme?

EN (English) and ES (Spanish) switch to the other language on the current page. The theme button enables dark or light mode and remembers your choice. You can enlarge the text with browser zoom.

How do I listen to music or watch videos?

In Interests, select “Listen to” or “Watch”. Close the player with the cross or Escape to stop it. Trailers use YouTube: its controls provide the captions and audio tracks available for each video. You can also open them with “Watch on YouTube”.

Is something not working?

If search says it needs JavaScript, use the site map or reading version. To save an address, use the copy button in its section. Confirmation appears beside that button. If automatic copying is unavailable, select the address and copy it manually. To report a problem, say which page you were on and what you were trying to do.
