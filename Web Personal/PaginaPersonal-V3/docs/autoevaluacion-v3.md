# Autoevaluación técnica de V3

Revisión de los 21 criterios usados en las valoraciones anteriores, con evidencias de V3. No se dispone en el repositorio de una plantilla específica «Plantilla-Métrica-WebPersonal (v3)»; esta revisión no sustituye su cumplimentación ni atribuye una nota numérica sin esa plantilla.

| Criterio | Estado observado en V3 y evidencia |
| --- | --- |
| 1.1 Comprensibilidad | Estructura conservada tras tres tareas completadas sin dificultades comunicadas. Menú y búsqueda con texto visible, página activa, migas e índices. |
| 1.2 Ayuda y retroalimentación | Ayuda bilingüe, estados de búsqueda, ejemplos, Limpiar y confirmación local de copia con recuperación de errores. Pruebas de navegador superadas. |
| 1.3 Estética | Identidad morada y composición de V2 conservadas. Revisión visual de portada, menú móvil, contacto, búsqueda oscura y texto ampliado. No hay valoración estética nueva de participantes. |
| 1.4 Móvil | 18 páginas en ocho tamaños de pantalla: 144 combinaciones sin desbordamiento horizontal. Controles de cabecera de al menos 44 px. Emulación en Chrome, sin afirmar pruebas físicas nuevas. |
| 1.5 Internacionalización | Nueve páginas por idioma; cambio equivalente ES/EN y consulta conservada. Metadatos `lang`, `hreflang` y canonical. |
| 1.6 Redes sociales | GitHub personal/universitario y LinkedIn propio, con enlaces descriptivos y aviso de apertura externa. Se mantienen los perfiles reales. |
| 2.1 Teclado | Salto al contenido, Tab/Enter, foco visible, menú con Escape y retorno de foco desde el reproductor. Comprobaciones de navegador; no se ha realizado una sesión con lector de pantalla. |
| 2.2 Sin gráficos | Navegación con texto y versión de lectura sin imágenes. Sin JavaScript siguen disponibles contenidos, direcciones, mapa y lectura. |
| 2.3 Herramientas de accesibilidad | Axe: 36 análisis, cero infracciones automáticas. Lighthouse: accesibilidad 100 en las cuatro páginas/configuraciones medidas. Permanecen límites de revisión humana y multimedia; WCAG AAA no acreditado. No se presentan como nuevas pruebas TAW, AChecker o WAVE. |
| 3.1 Buscador | 70 entradas bilingües; 15 casos del motor y 21 de navegador superados. Mejoras y documentación en `buscador-v3.md`. |
| 3.2 Navegación | Menú, portada, migas, categorías, ayuda, mapa y lectura. 536 referencias locales/anclas y destinos de las tres tareas comprobados. |
| 4.1 Aficiones | Se conservan videojuegos, rol, judo e intereses culturales, con categorías y enlaces a secciones concretas. |
| 4.2 Formación y experiencia | Formación y proyecto personal; Medicarama (2025) y V2c (2026) con los datos previamente aportados. No se añaden cargos o logros inventados. |
| 4.3 Contacto | Dos direcciones legibles, `mailto`, perfiles sociales y copia diferenciada, con confirmación y alternativa manual. |
| 4.4 Personas de referencia | Referencia personal aportada por el autor, diferenciada de sus perfiles y de las empresas. |
| 5.1 Errores | Enlaces, recursos, anclas, consola y contenidos revisados. Se mantiene la foto del gato con descripción correcta: no se dispone de una fotografía del autor. |
| 5.2 HTML | Nu Html Checker local: 18 páginas, cero errores y cero advertencias. Evidencia y hashes propios en `auditoria-v3/html-local.json`. |
| 5.3 CSS | css-tree local: cero errores de sintaxis/gramática comprobada. Valores con variables requieren comprobación en navegador; no es un resultado del servicio W3C CSS. |
| 5.4 Actualización | Fecha de revisión real visible: 20/11/2026, mediante elemento `time`. |
| 6.1 Rendimiento | Portada WebP adaptable, sin frameworks ni fuentes externas. Mediciones Lighthouse de V3 en `auditoria-v3/lighthouse-resumen.json`. |
| 6.2 Carga | Imágenes con dimensiones y carga diferida fuera de portada; audio sin precarga y YouTube bajo demanda. Estabilización de la cabecera y de la búsqueda al abrir consultas. |

El éxito observado corresponde a V2 y la muestra indicada, no a una evaluación humana de V3. Los resultados de herramientas tampoco equivalen a una calificación académica ni a una certificación de accesibilidad.
