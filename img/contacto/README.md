# Iconos de Contacto

- `github.svg`: Invertocat negro, descargado del [kit oficial de GitHub](https://brand.github.com/foundations/logo), archivo `GitHub_Invertocat_Black.svg` de `https://brand.github.com/GitHub_Logos.zip`. Se utiliza para enlazar los perfiles de GitHub. Se conserva el dibujo y su color.
- `correo.svg`: icono [Envelope de Bootstrap Icons](https://icons.getbootstrap.com/icons/envelope/), versión 1.13.1, obtenido de `https://raw.githubusercontent.com/twbs/icons/v1.13.1/icons/envelope.svg`. Licencia MIT incluida en `BOOTSTRAP-LICENSE.txt`.

Se retiraron los atributos de ancho y alto de los SVG para controlar su tamaño desde CSS, conservando el `viewBox` y las proporciones. El sobre usa el color fijo `#27272a` sobre un fondo claro para mantener el contraste en ambos temas. Los recursos se sirven localmente; no se ha incorporado el framework Bootstrap ni una fuente de iconos.
