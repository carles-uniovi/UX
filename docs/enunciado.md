# Trabajos (II): Sitio ADWeb

Se desarrollará un sitio ADWeb compuesto de varias páginas (mínimo 5) que contenga:

- Información personal (nombre, apellidos, email etc y una fotografía personal)
- Otra información: aficiones, actividades o principales temas de tu interés (películas, deportes, música, viajes, etc)
- Debe contener obligatoriamente fotos, videos y audios (podcast de tu interés)

- Se pueden usar las tecnologías que el estudiante considere necesarias
- En el archivo léeme.txt se debe indicar las tecnologías y justificar su elección.
- En caso de emplear bibliotecas, frameworks o herramientas adicionales, se deberán explicar las principales ventajas que aportan al desarrollo de la aplicación.
- El sitio web deberá ser técnicamente riguroso, cumplir los estándares web vigentes y utilizar correctamente las tecnologías seleccionadas
- Este sitio Web se usará posteriormente en la asignatura “Experiencia de Usuario (UX)”
