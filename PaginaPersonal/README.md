# Página personal

Sitio web personal de Carles Valladares García, desarrollado para el trabajo ADWeb del Máster en Ingeniería Web de la Universidad de Oviedo.

Incluye cinco páginas: presentación, trayectoria académica, hobbies, intereses y contacto. Cuenta con diseño adaptable, temas claro y oscuro y reproducción de audio y vídeo.

## Ejecutar

Abre `index.html` en un navegador moderno, conservando la estructura de carpetas. También puedes servir el proyecto por HTTP desde esta carpeta:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Después visita <http://127.0.0.1:8000/>. Detén el servidor con `Ctrl+C`.

## Tecnologías

HTML, CSS y JavaScript sin frameworks, dependencias ni compilación. Las imágenes, canciones y vídeos están incluidos en el proyecto.
