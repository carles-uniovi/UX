# Enunciado: No me hagas pensar

Trabajo opcional de Experiencia de Usuario (UX), del Máster Universitario en Ingeniería Web (MIW), convocatoria ordinaria.

**Calificación máxima:** 2 puntos.

## Análisis del libro

Se debe analizar el libro **«No me hagas pensar», 3.ª edición, de Steve Krug**.

Para cada capítulo del libro se debe:

- Extraer los conceptos que pueden ser susceptibles de ser calculados mediante una métrica.
- Proponer prompts para evaluar los conceptos anteriores utilizando inteligencia artificial generativa.

## Formato de entrega

Se debe entregar una **hoja de cálculo** que tendrá al menos tres columnas:

| Columna | Contenido |
| --- | --- |
| Capítulo | Cada uno de los capítulos del libro. |
| Conceptos identificados | Los conceptos identificados de cada capítulo. |
| Texto del prompt | El texto del prompt para cada concepto. |
